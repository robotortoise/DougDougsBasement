# DougDoug's Basement: How I Got a Sea Otter A Promotion!
Codebase for the visual novel DougDoug's Basement. Developed for the Rosa Charity Stream of 2024, this visual novel initially was intended as a short meme visual novel but ballooned into a beast that took from August until late November to finish. To compile the game, you'll need a copy of Naninovel and Text Animator plugins for Unity.

To build DougDoug's Basement, you'll need:
- Unity 6000 or later
- Naninovel 1.21
- Text Animator for Unity By Febucci
The latter two plugins are paid, but I highly HIGHLY recommend them. I love supporting independent developers, so you should, too! You can probably get away without the latter if you remove the Text Animator component from the printers just to build it, however.
Additionally, you MUST unzip the zip file "BGM_MoebiusBattle_Start_WithFieldTheme.zip" and leave the .wav file it extracts in the same directory. It is located at \Assets\Audio\BGM\BorrowedMusic. The full sized .wav file was too large for Github to handle, so I had to use this workaround (also, this is why I had to push so many commits with smaller files - sorry!!)

The actual game assets are archived [here](https://archive.org/details/DougDougVN-full), along with the [demo build of the game/DougDoug demo build. His version had a few gags altered, if I recall correctly.](https://archive.org/details/DougDougVN-demos) For example, one of these gags was the settings screen, which had a line directly to Twitch chat. We also cut out all Gerald Ford references, etc. That kind of thing.

I hope you enjoy! Poggies and all that.

- Jordan, writer and co-director.
